## What's new

- **Rotate the map** — `Q` / `E`, middle-drag, or drag the new compass in the
  top-right corner. Click the compass (or press `N`) for north up. Each zone
  remembers its own rotation.
- **Floors for multi-level zones** — Blind Midden, King Pyrotr's Fortress, the
  crypts, Tel Ekir and others now have a map per floor. Pick one from the
  **Floors** table on the map, or step through with `PgUp` / `PgDn`.
- **Maps show just the zone** — neighbouring zones' scenery, leftover
  development copies and backdrop terrain are gone. Vale of Zintar, Glass
  Flats, Shaded Dunes, Orc Island and others are now framed on the area you can
  actually reach.
- **Much more of each zone is drawn** — geometry the game keeps in its shared
  asset files, and Unity terrain, were being skipped. Keeper's Bight, Rothold,
  Scarwood and Glinting Hollow were mostly missing before.
- **Fixed** a dotted pattern covering large areas of some maps at close zoom.
- **Faster map generation** — about twice as fast, using all your CPU cores.
  How many zones build at once now depends on your free memory.
- **Choose which floors to build** — tick floors off in the **Maps** panel, or
  use **Floors only** to rebuild just the floors of the zones you select.
- **Experimental: painted style** — sidebar → **Experimental → Paint this map**
  renders the open zone in full colour. Desert colours only for now.

**Rebuild your maps after updating** (Maps… → All → Rebuild): the changes
above only apply to maps generated by this version.

## Install

A single self-contained executable. No installer, no runtime, and no map data
to download &mdash; it builds the maps itself from your own copy of the game.

**Linux**
```
tar xzf mnm-cartographer-*-linux-x86_64.tar.gz
./mnm-cartographer/mnm-cartographer
```

**Windows** &mdash; unzip and run `mnm-cartographer.exe`. Windows will warn
that the publisher is unknown, because the binary is not code-signed:
**More info -> Run anyway**.

On first launch press **Generate maps**. It finds your game install, reads the
zones from the game's own files and renders them. Expect a few minutes; maps
are written to your user data directory, not next to the executable, and come
to about 150 MB.

Put the executable wherever you like &mdash; it does not need to live in the
game folder.

If something looks wrong, run `mnm-cartographer --check` and include the
output in a report.

Verify a download against `SHA256SUMS.txt`.
